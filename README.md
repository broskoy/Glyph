# Glyph Art Association

A gallery and community website for the artists at Glyph.

## Features
- **Community Gallery:** A masonry grid displaying student artworks.
- **The Team:** A dynamic 3D carousel showcasing the members of the collective.
- **Secure Uploads:** A manual, invite-only authentication system ensuring only verified members can post and interact with art.

## Tech Stack
- Next.js 16 (App Router)
- React 19
- Prisma ORM + Local SQLite (Dev)
- NextAuth.js
- Vanilla CSS + CSS Modules
